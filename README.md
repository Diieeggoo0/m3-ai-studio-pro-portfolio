## 📌 Descripción & Propósito
Suite profesional de portfolio y servicios AI con selector dinámico de temas, telemetría serverless y diseño estilo Linear/Vercel.

---

## 🌟 Características Principales
- ⚡ **Rendimiento Ultrarrápido**: Sin dependencias pesadas, carga instantánea (<100ms).
- 🎨 **Diseño Moderno & Responsivo**: Optimizado para dispositivos móviles, tablets y escritorios.
- 🔒 **Serverless Architecture**: Preparado para endpoints seguros y telemetría sin exponer credenciales.
- 🚀 **1-Click Windows Deploy**: Incluye script interactivo `deploy.bat` para despliegues automáticos a GitHub y Vercel.

---

## 🚀 Despliegue Rápido en Vercel

1. Clona o haz fork de este repositorio:
   ```bash
   git clone https://github.com/Diieggoo0/M3-AI-Studio-Pro-Portfolio.git
   ```
2. Haz doble clic en el archivo `deploy.bat` o ejecuta en tu terminal:
   ```bash
   npx vercel --prod
   ```
